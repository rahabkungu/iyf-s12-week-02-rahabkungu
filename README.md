## What I learned
During this CSS assignment, I learned how to use CSS to style HTML webpages and make them look more attractive. I learned about:

- How to connect HTML and CSS.
- How to change text colors, font sizes, and background colors.
- How to add margin and padding to create space between elements.
- How to use CSS selectors to target HTML elements.
- How to add borders and style different sections of a webpage.
- How CSS improves the appearance and layout of a website.

  
 ## Challenges faced
 While working on this assignment, I faced several challenges:

 - Understanding how different CSS properties work.
 - Connecting the CSS file correctly to the HTML file.
 - Finding and correcting mistakes in my CSS code.
 - Understanding the difference between margin and padding.
 - Getting the styles to appear as expected on my webpage.

## How I overcame the challenges
I overcame the challenges by practicing, reviewing my code, checking for errors, and trying different CSS properties to understand how they work.

## Conclusion
This assignment helped me improve my understanding of CSS and how it works with HTML. I am still learning, and I look forward to improving my styling skills and creating more attractive and responsive websites.
