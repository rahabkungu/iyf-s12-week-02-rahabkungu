## Project Description
This project was created as part of Week 2 of the IYF We Can Academy web development training. The main objective was to learn and practice CSS by styling HTML webpages and improving their appearance, layout, and design.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

## Features
- Styled HTML elements using CSS.
- Applied different colors, fonts, and backgrounds.
- Practiced CSS selectors and properties.
- Improved webpage layout and appearance.
- Used CSS to make webpages more attractive and user-friendly.

## How to Run
1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. View the webpage and its CSS styling.

## Lessons Learned
- Understanding the basics of CSS.
- How to link an external CSS file to HTML.
- Using CSS selectors to target HTML elements.
- Applying colors, fonts, margins, padding, and borders.
- Understanding how CSS improves webpage design.
- Practicing how HTML and CSS work together.

## Challenges Faced
- Understanding how different CSS properties work.
- Getting the correct layout and spacing.
- Connecting the CSS file correctly to the HTML file.
- Fixing styling mistakes and improving the webpage appearance.

I overcame these challenges through practice, testing different CSS properties, and correcting errors in my code.
